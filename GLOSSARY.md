# Brightspace Session Access

Language for saved Brightspace credentials and passphrase access.

## Language

**Saved browser session**:
A locally stored set of Brightspace browser credentials for one school's Brightspace site.
_Avoid_: School account, passphrase

**Unlocked session**:
A passphrase-protected saved browser session that has been successfully decrypted with the supplied passphrase.
An unlocked session may still require a new school login if Brightspace no longer accepts its credentials.
_Avoid_: Verified school login
